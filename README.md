# Loop the App
Your city, unlocked.

This app connects travelers with locals to discover hidden gems and hot spots that only residents know about. Making traveling more effective, where travelers can search by city, and search through recommendations that come directly from locals, and provide the ability to save the favorite spots to help build their own personalized itinerary.
